# 色彩

方向单会发给你一套带有命名角色的配色。本文件说明如何应用它，好让页面看起来像是经过
决定的，而不是被染了色。

## 1. 研究测到了什么

- 所研究的页面中 41% 是深色，59% 是浅色。四分之一落在纯白上；12% 落在纯黑上。
- 按评审组的分类，配色方案为：单色加一个强调色 23%，浅中性色 22%，深中性色 14%，
  若干平涂颜色 13%，严格双色 12%，由照片承载颜色 9%，一整块饱和色域 6%。
- 52% 的站点按钮是中性的（黑、白、灰）。彩色按钮是一种选择，不是必需品。
- 渐变填充出现在 22% 的高分站点和 52% 的弱站点上；渐变文字是 2% 对 13%。
- 246 个站点中有一个使用赤陶色主按钮，没有一个使用紫罗兰色。那些是生成页面的颜色，
  不是画廊的颜色。暖白色底确实存在（32 个站点），几乎总是配深色或绿色的墨，而不是
  橙色的强调色。
- 高分站点更频繁地在分区之间改变页面的底色（分区底色的中位数是两个，对照组是一个）。

## 2. 各个角色

```css
:root {
  --bg: …;          /* the ground: most of the surface */
  --surface: …;     /* one tone step from the ground: filled panels, form fields, tiles */
  --ink: …;         /* main text and the strongest marks */
  --muted: …;       /* secondary text; still passes contrast on --bg */
  --accent: …;      /* the one accent */
  --accent-ink: …;  /* text on the accent */
  /* --field-1 … --field-n and their inks, when the palette has section fields */
}
```

构建中的每一种颜色都要用这些令牌。组件里出现一个裸的十六进制色值，就是第二套配色的
开始。不要在角色之间插入灰色：如果你需要更安静的文字，那就是 `--muted`；如果你需要更
安静的表面，那就是 `--surface`。

## 3. 比例

在给任何东西上色之前先定下份额，并在截图里核对它们：

- **底色：** 页面的 70–90%。
- **墨：** 文字，也许再加一个反色分区（墨作底、底作墨）。
- **强调色：** 在任何一屏上都低于 5%。它标记动作，至多再标记另一件反复出现的东西。一旦它
  出现在五个地方，它就不再意味着“这里”。

带有色域的配色（平涂大字、粉彩）运作方式不同：每个分区就是一整块足力的色域，比例规则
在每个分区内部适用（色域、它的墨，别无其他）。

除非方向单另有说明，强调色不用于标题、图标、项目符号、边框或下划线。标题是墨。

## 4. 不用线也不用阴影的表面

在分隔线与阴影被禁用之后，表面只能靠色调与底色区分：

```css
.panel { background: var(--surface); }          /* 2–6 lightness points from --bg */
.field { background: var(--surface); border: 0; } /* inputs: filled, with a clear focus state */
.field:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }
```

- 一个步阶就够了。如果一块面板读不出来，先增加内边距或用空间把它分开，再去考虑第二个
  色调。
- 不要在面板里再嵌一块面板。
- 图片不需要边框。如果一张浅色照片溶进了浅色底色，换裁切，或者把它放在 `--surface` 上，
  不要给它描边。
- 用墨或强调色画的粗条（4px 或更粗）是图形元素，在方向用到它的地方是允许的。1px 的线
  不是。

## 5. 色域

一个改变整块底色的分区是现有最强的色彩动作，它一次就替代了分隔线、卡片和背景装饰。

- 色域与色域以硬边相接。什么都不渐变过渡。
- 每个色域都有配色为它指定的墨。绝不要把 `--muted` 放在彩色色域上；要用该色域自己的
  足力墨，或者在仍然通过对比度时用 70% 不透明度作次要文字。
- 相邻色域应当在明度上不同，而不只是色相上不同，否则页面会发颤。
- 像安排章节一样安排它们：开得有力，歇一歇，来点意外，用深色或极浅色收尾。
- 页面的 meta 主题色与导航跟随第一个色域。

## 6. 深色页面

- 在根元素上设置 `color-scheme: dark`，让表单控件与滚动条跟随。
- 底色是带一点配色色调的深色，墨是柔和的浅色，而不是 `#000` 上的 `#fff`，除非配色为
  一个冷峻的双色方向正好发的是这一组。
- 次要文字是深色页面翻车的地方：核对 `--muted` 与底色的对比（4.5:1）。
- 深色上的层次来自更亮的表面步阶，绝不来自光晕或彩色光。
- 相比在浅色页面上，使用更轻的字重。

## 7. 色彩与照片

- 当照片承载颜色时，界面保持中性，并从图像中最深的色调中取墨。
- 不要用品牌色去洗一张照片。要么不动它，要么为页面上每一张图片坚持一种真实的处理
  （全部灰度，或者全部不动）。
- 照片上的文字需要一块平静的区域。如果没有，就把文字移出图片。中性的遮罩层（黑色或
  墨色，30–55% 不透明度，平涂或只在文字区域上渐隐）是检查器允许的唯一一种渐变。
- 从照片里取样的平涂色域（它的天空、它的阴影）能让一个分区与那张图坐在一起。

## 8. 对比度

- 正文 4.5:1 或更好；展示字体与大号数字 3:1 或更好；所发配色在墨与底色之间达到 7:1。
- `inspect.mjs` 会计算平涂底色上文字的对比度，并让任何低于 2.6:1 的项不通过。它看不到
  照片上的文字：那些要你自己在截图里核对。
- 不要为了让文字“柔和”而降低它的不透明度，除非你已经核对过由此产生的比值。
- 焦点态与悬停态只提高对比度，绝不降低。

## 9. 被禁用的色彩家族，以及这里的“暖”指什么

检查器会让这些不通过：

- **奶油色配赤陶色。** 黄奶油色底（大致色相 22–62，明亮且有明显饱和度）配铁锈色、陶土色
  或焦橙色的强调色，是 AI 助手及其生成页面的招牌外观。两者单独出现都可疑；一起出现则
   绝不会被认错。
- **紫罗兰色与靛蓝色。** 第一波生成页面是紫色的；它到现在读起来仍然如此。

如果简报想要暖意，就从低彩度的石色、骨色或油灰色底（饱和度大约低于 15%）里取，从深绿、
棕色或牛血色的墨里取，从照片里取，或者从一整块暖色域（芥末黄、番茄红、粉色）里取——
平涂使用，并且带着确信。暖不是米色。

如果品牌本身拥有其中一种被禁用的颜色，那它就是品牌的，你保留它：使用
`--keep palette`，向检查器传入 `--allow palette-purple`（或相应的规则），并在报告里注明。
