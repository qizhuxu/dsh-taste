# 破绽 —— 带日期的登记表

破绽（tell）是一种让页面读起来像是生成出来的手法。破绽本身并不等于糟糕的设计；大多数
破绽最初都是好站点上的好点子。它们之所以成为破绽，是因为被默认地、无处不在地、毫无
理由地生产出来。这就是为什么这份登记表带有日期，也为什么它从不指名某个替代字体、颜
色或组件：每一份公开发布的“改用这个”清单，都在几个月内变成了下一波破绽。这里的替代
方案是流程（从库中抽取、从主题中推导），不是产品。

`scripts/inspect.mjs` 与 `scripts/lint.mjs` 能检出其中大部分条目。状态：**禁用**表示
检查器会让页面不通过；**警告**表示它会标出该项，你需要给出理由。

## 1. 第一波（2023–2024）

| 破绽 | 状态 | 替代做法 |
| --- | --- | --- |
| 首屏、按钮和光晕上的紫罗兰色 / 靛蓝色渐变 | 禁用 | 抽到的配色；平涂颜色 |
| 用渐变填充的标题文字 | 禁用 | 实色墨 |
| 玻璃面板：背景模糊、半透明卡片 | 警告（2 个及以上） | 不透明表面，与底色相差一个色调步阶 |
| 发光或带渐变的“开始使用”按钮 | 禁用 | 以自己的动作命名的平涂按钮 |
| 每张卡片下方柔和的灰色投影 | 禁用 | 色调步阶，或者不要盒子 |
| 三张完全相同的功能卡片，每张都有一个装在圆角方块里的图标 | 禁用 | 抽到的分区蓝图 |
| 用 emoji 充当图标或项目符号 | 禁用 | 文字，或者一张真实的图片 |
| 居中标题、副标题、两个按钮、下方一张截图 | 无规则；抽取会避开它 | 抽到的首屏 |
| 每个生成的页面都用同一种字体 | 警告（lint: default-font） | 抽到的字体系统 |

## 2. 第二波（2025）

| 破绽 | 状态 | 替代做法 |
| --- | --- | --- |
| 眉标 / 引题：每个标题上方那个小号、加字距的大写标签 | 禁用 | 把它揉进标题里，或者删掉 |
| 首屏标题上方的胶囊徽章（“New”“Beta”“Introducing”） | 禁用 | 在支撑句里说明 |
| 标题里有一个词用斜体衬线、换成异色或加下划线 | 警告 | 一种字体，一种颜色 |
| 用圆角瓦片构成的 Bento 网格充当功能分区 | 作为卡片行时警告 | 一个经过构思的分区；瓦片只用于密集瓦片方向，填充内容、尺寸严格 |
| 近黑底色加一个霓虹强调色和一片光晕 | 通过阴影、渐变判为禁用 | 抽到的深色配色，没有光晕 |
| 带模糊的悬浮圆角胶囊导航 | 警告 | 一条朴素的栏 |
| 用灰条和环形图拼出来的假仪表盘首屏 | 无规则；见 imagery.md §7 | 一段真实的界面片段，或者不放图片 |
| 装饰性状态点（“Available for work”、脉动的“live”） | lint: bounce | 移除 |
| 每个分区都做的淡入上浮 | 无规则；见 motion.md | 一个标志性动作 |

## 3. 第三波（2025–2026）：变成那副样子的“修正”

为前两波公布的补救方案是“把它暖起来，做得像编辑排版”。模型们把这条补救方案全盘照搬，
于是它成了所有生成物中最容易辨认的那副样子。

| 破绽 | 状态 | 替代做法 |
| --- | --- | --- |
| 黄奶油色底 + 赤陶色 / 铁锈色 / 陶土色强调 | 同时出现时禁用；赤陶色单独出现也禁用；奶油色警告 | 抽到的配色。暖意来自低彩度的石色、一种深墨、一张照片，或者一整块暖色域 |
| 用高对比或柔和衬线展示字体充当通往“高级感”的捷径 | 无规则 | 抽到的字体系统，无论它属于哪一类 |
| 超大斜体衬线标题 | 无规则 | 按抽取结果 |
| 大报模仿秀：到处是细线、零圆角、密集分栏 | 通过细线判为禁用 | 用空间与色调建立结构 |
| “Field notes”“Quietly trusted by”“On our desks”：表演性的标签 | lint: copy | 朴素的分区名称 |

## 4. 画廊时尚，作为自定风格被禁用

这些在当下的获奖站点上很常见。在研究中，它们出现在高分站点上的频率反而*高于*弱站点
（评审组观察：等宽字体标签 44% 对 24%，序号编号 38% 对 21%；测得的细线 61% 对 52%）。
即便如此，它们在这里仍被禁用，这是所有者的决定：它们是生成器从画廊里最先抄走的东西，
不携带任何信息，而一个不靠它们建起来的页面必须找到真正的结构。

| 破绽 | 状态 | 替代做法 |
| --- | --- | --- |
| 等宽字体微型标签、把等宽当作“技术感”的声音、等宽图注 | 禁用 | 正文字体；数据用表格数字 |
| 序号编号：01 / 02 / 03、(001)、“Step 02”、带编号的分区标记 | 禁用 | 用位置、尺度或词语来排序；真正是列表时用 `<ol>` |
| 细线：发丝分隔线、带线的网格、1px 描边的盒子与瓦片 | 禁用（盒子：3 个及以上） | 空间、色调步阶、填充形状，如果条本身就是那个创意，就用粗条 |
| 把设计工具的界面元素当装饰：十字准星、裁切标记、选择手柄、虚线参考线、标尺 | 通过细线、虚线判为禁用 | 移除 |
| 代理机构微元信息：本地时间、坐标、天气、版本戳、“©2026 — Scroll”、中点分隔的字符串 | lint: copy；微型标签 | 移除 |
| 视口里四处散落的小号、加字距的大写图注 | 禁用（3 个及以上） | 用句子大小写在可读的字号下，放在它所描述的内容旁边 |

小号加字距的大写是本组里唯一连数据也谴责的一项：高分站点 16%，弱站点 57%。

## 5. 结构破绽

| 破绽 | 状态 | 替代做法 |
| --- | --- | --- |
| 标题写成一整句展示字号的话，占三到四行 | 禁用（超过两行） | 大约五个词的标题；其余内容放到下面 |
| 套路的区块顺序：首屏、标识、功能、证言、定价、行动号召 | 无规则；见 copy.md §1 | 按论证的顺序 |
| 每个分区都用同一种布局家族 | critique.md 第 9 遍 | 每个分区换一种构图，从单子上取 |
| 一切都居中 | 超过 72% 时警告 | 左对齐，只保留一处居中 |
| 所有东西都用同一种中等圆角（12–16px） | 无 | 要么方角要么全圆，只选一次 |
| 九种几乎相等的字号 | 超过 9 时警告 | 五种字号，彼此拉开 |
| 编造的社会证明：标识、引语、星级行、“10,000+ teams” | copy.md §5 | 真实的证明，或者没有 |
| 该放图片的地方放了文字或一个 CSS 盒子 | critique.md 上限 | 一张真实的图片，或者一个本就不需要图片的设计 |

## 6. 文案破绽

由 `lint.mjs` 标出：这一类型的动词与形容词（unlock、supercharge、seamless、elevate、
effortless、cutting-edge、all-in-one……）；纠正句式（“not just X, it's Y”）；三连标题；
把“Get started”和“Learn more”当作标签；多于寥寥几个的破折号；lorem ipsum。见
`copy.md` §6。

## 7. 动效破绽

每个区块都一样的上浮淡入；十几次错落的首屏入场；每张卡片都有的悬停上抬；回弹缓动；
毫无意义的无限循环；播放失败并留下一段空白带的入场揭示。见 `motion.md` §9。

## 8. 为什么仅仅移除还不够

把每一个破绽都移掉、却不在它们的位置上放任何东西的页面，是一个有礼貌的空页面，而那
也是一种破绽（“回避美学”：任何人都能从品类加上那份要避免的清单里猜出它来）。破绽
原本填的是一个本该由创意占据的空缺。`SKILL.md` 里的工作顺序就是为先把那个空缺填上而
存在的：从主题中来的创意、抽到的构图、真实的图片或坚定的字体，最后才是各项检查。
